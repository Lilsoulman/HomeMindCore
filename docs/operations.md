# HomeMind 运行与部署

## 本地运行

```powershell
dotnet run --project HomeMind.Api
```

服务根路径会跳转 Swagger；默认开发地址以启动日志为准。先准备数据库连接、令牌密钥和所需外部服务配置，再进行跨端联调。

## 生产发布检查

- 使用生产级令牌密钥和数据库凭据，禁止提交到仓库或返回客户端。
- 将 CORS 从开发环境的任意来源改为明确的移动 Web/Web 域名白名单。
- 按顺序执行 `database` 目录下的迁移，并在备份和预发布环境验证。
- 为 API、数据库、对象/文件存储和外部 Connector 配置健康检查、日志、告警和备份。
- 验证 Swagger、登录、令牌刷新、一个只读接口、一个写接口和一个异步运行/失败路径。

## 外部依赖原则

MCP、Home Assistant、渲染工具和第三方 Connector 都是可选依赖。缺失、超时或响应不兼容时服务必须返回可识别的失败（通常为 `502/503`），禁止用 mock 或伪造结果冒充成功。凭据由服务端或本地受控进程管理，不写入日志和 API 响应。
